# Party symbol image sources

Every file here is a real image of the actual ECI-reserved election symbol,
downloaded from Wikimedia Commons and verified by visual inspection before use
(each was rendered and looked at, not just trusted by filename). None are
hand-drawn or approximated — where no verified image could be found, the app
shows "symbol not confirmed" instead of a substitute.

All are licensed CC BY-SA (3.0 or 4.0) — reuse is allowed with attribution,
which is why this file exists.

## Verification note on the elephant

Wikimedia Commons also hosts `Elephant_Bahujan_Samaj_Party.svg` — BSP's own
colored party logo (white elephant on a blue background). That is NOT what's
used here. The file above is the black-and-white line-art version, matching
how the symbol actually appears on an EVM/ballot paper and matching the
rendering style of every other symbol in this set. Using the colored logo
instead would have been technically "a real image" but not the thing a voter
looks for on the ballot — checked and rejected for that reason.

## Not included — no verified image found

**Jan Suraaj Party (School Bag).** Searched Wikimedia Commons directly; no
image of this symbol was found there as of 2026-07-27 (it's a newly allotted
symbol, 2025). The app shows "symbol not confirmed" for this party rather than
drawing a school bag from imagination.

Everything else contesting in the three tracked constituencies (Rashtriya
Jansambhavna Party, Right to Recall Party, Bharatiya Momin Front, and other
small/independent contestants) has no ECI-*reserved* symbol at all — those
parties are allotted a free symbol per constituency, which can differ seat to
seat, so hard-coding one would misrepresent it. These correctly show "symbol
not confirmed."
